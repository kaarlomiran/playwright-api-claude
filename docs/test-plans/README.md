# Test plans

Generated by the `test-plan-generator` skill, one file per feature:
`docs/test-plans/<feature>.md`. Each plan maps every acceptance criterion (AC-n)
to one or more test cases (proposed TC IDs, category, method/endpoint, request,
expected status/body, assertions). Review and edit before approving; only approved
plans are registered into `docs/test-cases.json` and scripted.
